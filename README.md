# 📝 기사 프로젝트 노트

기사 프로젝트를 정리하는 노트 페이지예요. HTML 파일 하나로 되어 있어서 설치나 서버 없이 브라우저에서 바로 열 수 있고, 폰 화면에서도 잘 보여요.

## 구성

| 칸 | 설명 |
| --- | --- |
| 🎯 프로젝트 한 줄 | 프로젝트 브리프를 한 줄로 적는 칸 |
| 🏷️ 주제 | 대주제 **경제** |
| ✅ 할 일 체크리스트 | 할 일 5개를 적고 체크하는 칸 (체크하면 취소선) |
| 🗓️ 날짜별 기록 | 11/18부터 시작하는 타임라인. 날짜마다 한 줄씩 기록하고, "+ 다음 날짜 추가" 버튼으로 이어 쓸 수 있어요 |

## 사용 방법

1. `기사_프로젝트_노트.html` 파일을 내려받아요.
2. 브라우저(크롬, 사파리 등)에서 파일을 열어요.
3. 칸을 눌러서 바로 적으면 돼요.

## 저장

적은 내용은 사용 중인 브라우저의 로컬 저장소(`localStorage`)에 자동으로 저장돼요.

- 내용은 이 기기, 이 브라우저에만 남아요. 다른 기기나 다른 브라우저에서는 보이지 않아요.
- 브라우저의 사이트 데이터를 지우면 적은 내용도 같이 지워져요.

## 디자인

- 노션이나 메모처럼 읽기 편한 레이아웃
- 핑크 그레이 컬러
- 휴대폰 화면에서는 날짜 기록이 한 줄 레이아웃으로 바뀌어요

## 참고

- 전화번호, 주소 같은 개인정보 칸은 없어요.
- 외부 라이브러리나 네트워크 요청 없이 파일 하나로 동작해요.
